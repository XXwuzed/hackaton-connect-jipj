# Club de Fidelización Farmaenlace - Monorepo

Sistema de fidelización de clientes de Farmaenlace (MVP).

## Estructura del Monorepo

- `hackaton-backend/`: Servidor API REST (Node.js, Express, PostgreSQL / Prisma)
- `hackaton-dash-frontend/`: Panel de intranet para administradores y asesores comerciales (React / Vite)
- `hackaton-form-frontend/`: Formulario público de registro por código QR para clientes (React)
